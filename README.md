### 🎯 Course Objectives
The course aims to develop the ability to:
- Understand and implement abstract data types and fundamental data structures using C++.
- Design algorithms that solve computational problems involving organized data.
- Analyze the time and space complexity of algorithms and common data structure operations.
- Compare algorithmic approaches based on their efficiency and suitability for specific problems.
- Implement and evaluate algorithms through practical programming exercises and performance measurements.
- Apply data structures and algorithms in developing effective software applications that address engineering-related problems. <br>

### 🗺️ Course Roadmap
The course topics are organized into three major academic periods.
| **Period** |	**Major Topics** |
|---|---|
| **Prelim** |	Course orientation, C++ programming review, abstract data types, time and space complexity, arrays, linked lists, dynamic memory allocation, and stacks |
| **Midterm**	| Queues, searching techniques, linear search, binary search, hashing, and basic sorting algorithms |
| **Finals** |	Trees, binary search trees, AVL trees, traversal algorithms, graphs, adjacency matrices and lists, breadth-first search, depth-first search, and algorithm complexity analysis | <br>
